# About this site
A single-page portfolio that presents my projects, internship experience, skills and education in one place. 
It is built to be quick to read for recruiters and hiring managers: the strongest project and its measured result are visible at the top of the page.

# Built with
HTML and CSS in a single index.html file, with no frameworks or build step
A small amount of CSS animation, turned off for visitors who prefer reduced motion
Google Fonts: Bricolage Grotesque and Instrument Sans
Hosted free on GitHub Pages
Features
Responsive layout for phones, tablets and desktops
Light and dark mode that follows the visitor's device setting
Semantic HTML, keyboard-friendly focus styles and readable contrast
Fast loading, since there are no images or scripts to download

# Clone the repository:
bash
git clone https://github.com/supraja-ulaganathan/supraja-ulaganathan.github.io.git
Open index.html in any browser.
Deploy your own copy
Create a public repository named <your-username>.github.io.
Upload index.html to the top level of the repository.
Go to Settings → Pages, choose Deploy from a branch, select main and / (root), and save.
Your site will be live at https://<your-username>.github.io within a few minutes.
